# img == 图形图像文件夹

## 子文件夹说明

- animations == 技能动画切片
  - 数据库「动画」里配置的特效帧图,火球、斩击、治愈光那种。
- battlebacks == 战斗背景
- characters == 角色行走图
  - 地图上玩家、NPC、事件的站立/行走图,以及宝箱、门、树这类可交互物件。一张图默认按 4 方向 × 3 帧 = 12 格排列;文件名加`$`前缀表示单角色不切格，加`!`前缀表示不往上偏移 6 像素、也不受草丛半透明影响(常用于门/箱子)。
- enemies == 敌人战斗图
  - 回合制前视战斗里显示的怪图,尺寸随意,建议用偶数宽避免发虚。
- faces == 对话头像
  - 菜单和对话窗口左侧的小头像。一张图是 2 行 × 4 列共 8 个 144×144 的表情格。
- parallaxes == 远景图 / 视差背景
  - 挂在地图背后的滚动背景,比如星空、远山、云层。尺寸随意，可循环平铺；文件名以`!`开头会被当成地面层而不是远景。
- pictures == 事件图片
  - 事件指令「显示图片」能选到的图,用来做 CG、过场、自定义 UI、标题 LOGO、地图截图等。尺寸随意,PNG 带透明通道。
- sv == 战斗时横版侧视
- system == 系统图(UI 大杂烩)
  - 放各种引擎内置界面元素,常用文件:
    - IconSet.png == 道具/技能/状态的小图标集
    - Damage.png == 伤害数字字体图
    - Balloon.png == 角色头顶的心情气泡
    - ButtonSet.png == 触屏按钮(手机端)
    - GameOver.png == 游戏结束画面
    - Loading.png == 读取界面
    - Window.png == 窗口皮肤
    - States.png、Shadow1/2.png、Weapons1~3.png == 状态图标、影子、横版武器动作
    - ...
- tilesets == 地图图块(地砖)
  - 拼地图用的"积木"。
- titles == 标题画面
