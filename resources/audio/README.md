# audio == 声音相关的文件夹

## 子文件夹说明

- bgm == Background Music (背景音乐)
  - 地图、标题画面、战斗等场景里循环播放的主音乐,比如城镇主题曲、boss战配乐。通常是一整首曲子，会一直循环。
- bgm == Background Sound (背景声音/环境音)
  - 不是音乐,是环境氛围声,比如雨声、风声、鸟叫、人群嘈杂、篝火噼啪声。一般也循环,但音量低、 layered 叠加播放，用来让场景"活起来"。
- me == Music Effect (音乐效果/短曲音效)
  - 一段短小的演出音乐,用来配合特定事件瞬间播放,比如住店过夜的小旋律、战斗胜利 jingle、游戏结束曲、剧情高潮闪现的 sting。特点是短、有优先级,常会压过 BGM 一下。
- se == Sound Effect (音效)
  - 最细碎的那类：瞬时反馈声,攻击挥砍、法术爆破、菜单点击、开门、脚步、受伤……基本所有"叮咛咣当"都放这。
